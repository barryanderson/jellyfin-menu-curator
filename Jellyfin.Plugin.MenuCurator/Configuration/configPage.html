Menu Curator

Choose which plugin pages appear in the dashboard menu, what they are called, their icons and their order.

Saving reloads the dashboard so the menu updates straight away.

In the menu

Untick a page to remove it from the menu; its settings stay available from Dashboard > Plugins. Leave a name blank to keep the plugin's own. The first icon in each list is the plugin's own, or the folder icon if the plugin has none. The menu can only show Material icons, not plugin logos; choose "Custom icon name" to use one that is not listed.

Other pages

Pages their plugins leave out of the menu. Tick one to add it.

Rules for pages that are not loaded

These rules refer to pages from plugins that are disabled, removed or renamed. They have no effect until the page returns. Untick a rule to delete it.

Plugins with no settings page

These plugins register no page, so they cannot appear in the menu.

    Reset

    Delete all Menu Curator settings and return the menu to what the plugins themselves ask for. You can also run the "Reset dashboard menu" task from Dashboard > Scheduled Tasks.
